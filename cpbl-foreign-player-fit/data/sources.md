## Official sources: status after amendment 1 (2026-10-13)

The environment owner allowed `stats.cpbl.com.tw`, `baseballsavant.mlb.com` and `statsapi.mlb.com` on 2026-10-13. All three now answer HTTP 200.

| Source | Status | Use |
|---|---|---|
| `statsapi.mlb.com` | Reachable; no robots.txt | **Used** (rows 6–7): AAA pitch data for 2025-05-20 onward and 2026, roster facts, official eligibility cross-check |
| `baseballsavant.mlb.com/statcast-search-minors` | Reachable; robots.txt allows all | Not needed: the CSV export works only per player, and the same pitches come from the statsapi feed |
| `stats.cpbl.com.tw` | Reachable. **Not used for the ranking; used for validation since amendment 7 (rows 15–16)** | Pages are server-rendered shells; the numbers load from `/api/`, which robots.txt disallows. The site's terms (使用條款 §4) forbid using, reproducing or distributing its content without written authorization, and its `Content-Signal` header says `ai-train=no`. The leaderboard has an in-page 「匯出表單」 button, but exported data falls under the same terms. 2026 CPBL data therefore needs written permission from CPBL (or explicit cover in the contest rules). On 2026-10-14 Johnny decided to use public pages and the export button without it, for backtest outcomes and calibration only (limitations L10). |
| `www.cpbl.com.tw` | Not tested again | official box scores |

## Reproduce

```bash
pip install -e .[dev]              # plus statsmodels, scipy
python -m src.fetch_data           # downloads 1-5, builds chadwick tools (~2.5 GB raw CSV)
python -m src.statsapi_pbp         # source 6: 3,681 AAA game feeds (~90 MB gzipped, resumable)
python -m src.eligibility          # MLB season lines (Retrosheet -> cwdaily)
python -m src.roster_status        # source 7 (also run automatically by src.evaluate when missing)
python -m src.cpbl_profile         # CPBL/AAA environment profiles + figures 1-4
python -m src.data_audit           # reports/data_audit_summary.md
python -m src.park                 # source 11 + amendment 5 park factors (also run on first use)
python -m src.baseline_weights     # source 10 + amendment 4 weights (also run by src.evaluate when missing)
python -m src.evaluate             # candidates, signability tiers (source 12), baseline, Fit, Tests A-D, figures 5-6
python -m src.recruitment_backtest # sources 12-14: amendment 6 recruitment backtest
python -m src.cpbl_site            # source 15 (pages; never /api/)
NODE_PATH=$(npm root -g) node tools/cpbl_site_export.js 投手 0 data/raw/cpbl_site/exports/pr_pitcher_2026.xlsx   # source 16, see the script header
python -m src.statsapi_release 2025 2023 2024   # source 17
python -m src.stuff_plus           # amendment 8 Stuff+ and its validation
python -m src.velocity_calibration # amendment 7b item 4
python -m src.backtest_2026        # amendment 7 / 7b item 3
pytest -q
```
